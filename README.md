# 💳 Pricing Plans Layout

A responsive pricing tiers component built using semantic **HTML5** and **CSS3 Flexbox**, demonstrating custom ordering, flexible container wrapping, and precise column layouts.

---

## 📌 Overview

The **Pricing Plans Layout** project highlights advanced Flexbox control techniques, such as managing item order sequence via the `order` property, controlling growth distribution with `flex-grow`, and aligning internal card elements cleanly using `justify-content: space-between`.

---

## ✨ Key Features

- **Flexible Container Grid**: Utilizes `display: flex` and `flex-wrap: wrap` for adaptive multi-device layout behavior.
- **Customized Flex Order**: Re-orders cards (`basic-plan`, `pro-plan`, `premium-plan`) using CSS `order` properties.
- **Controlled Flex-Grow**: Expands the Pro tier card dynamically using `flex-grow: 2`.
- **Structured Content Cards**: Internal column alignment separating headers and pricing tiers efficiently.

---

## 🛠️ Built With

* **HTML5**: Semantic document structure.
* **CSS3**: Flexbox layouts, borders, and spacing properties.
